other) live in [CLAUDE.md](CLAUDE.md). The file name is historical, and the
contents apply to all agents. Read it before doing anything else.

  [lib/mechanics/MODEL-RESEARCH-GUIDE.md](lib/mechanics/MODEL-RESEARCH-GUIDE.md).
- **Building or changing mechanic detection:** read
  [lib/mechanics/README.md](lib/mechanics/README.md).
