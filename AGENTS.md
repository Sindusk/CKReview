# Agent Instructions

This repository's instructions for **every** AI agent (Codex, Claude, or any
other) live in [CLAUDE.md](CLAUDE.md). The file name is historical, and the
contents apply to all agents. Read it before doing anything else; its docs
map routes each task to the right file. Skills referenced there live in
`.claude/skills/<name>/SKILL.md` — agents without skill support read that
file and follow it directly.
